## DT-3：外壳

状态：在做（2026-10-30）。

### 目的

照 `docs/blueprint/desktop.md` 写出桌面端的外壳 `miyu-desktop`：一个窗口开网页软件给的本机地址，关窗口藏进托盘，托盘「退出」连核心一起停。三个平台都编得过、测试过，Linux 上本机手测一遍，正式版量藏着时的内存。

### 蓝图改哪几节

- `docs/blueprint/desktop.md`：写的时候发现和图纸不一样的地方照实改（「怎么走」第 12 条 macOS 的应用菜单自己建，见「要拍板的」）。

### 要拍板的

- macOS 的 `⌘Q`：彻底退出，和托盘「退出」同一条，连核心停（项目主人 2026-10-30 定）。
- macOS 的应用菜单外壳自己建：「退出 Miyu」（`⌘Q`）走彻底退出，「编辑」一栏用系统的（复制、粘贴、全选这些），「窗口」一栏的关闭同关窗口。Tauri 默认的菜单里「退出」直接退外壳、不经外壳的退出那一条，所以不用它。

### 不做什么

- 图标：先用原图缩的占位图标，DT-5 换。
- 安装包：DT-6。这一步 CI 只编译、clippy、测试。
- macOS、Windows 的通知：等 CI 出的程序实测，接不住的记下来找网页。

### 验收

1. 纯逻辑的单测（导航、读那一行 JSON、找主程序、下载的名字、三份字）改代码之前是红的。
2. 本机 Linux 手测：开窗口免密进来；外链交系统浏览器；下载进「下载」目录；关窗口藏起来、托盘「显示 Miyu」拿回来；第二次开程序叫回窗口；藏着时页面照旧弹通知、点通知拿回窗口；托盘「退出」核心停了（`run/core.lock` 放了）、外壳退了；`miyu` 找不到、`miyu web` 出错时弹对话框。
3. release 版藏着 5 分钟的内存（外壳、网络进程、网页进程的 Pss 合计）记在这里。
4. CI 三平台编译、clippy `-D warnings`、测试全绿；每个 `.rs` 不超过 500 行。

### 风险

- Linux 上没有 `libayatana-appindicator` 的建不出托盘：记一行日志、照旧开窗口，没托盘时靠再开一次程序叫回窗口。
- 窗口状态插件把「藏着」也记下来，下次起来窗口不出来：只记大小、位置、最大化。
