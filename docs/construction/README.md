## 桌面端的施工

一步一张施工单，格式照核心仓库 `docs/construction/README.md` 第四节（目的、蓝图改哪几节、要拍板的、不做什么、验收、风险）。编号是 DT 线（2026-10-29 和核心的主会话定）；碰核心、网页仓库的那几步在那边开 `step/` 分支，照那边的规矩合。

### 一、项目主人定了的（2026-10-29）

1. 用 Tauri，做成网页的薄封装：窗口开网页软件给的页面，页面、`/media`、`/page` 不在外壳里重写；外链、下载、剪贴板、通知由外壳在网页视图外面接住。
2. 免密：外壳每次开窗口调 `miyu web --print --format json --ticket`，拿一个带交接票的网址（核心 LT-1，60 秒、一次性；网页 W-977、W-978）。本机的人读得到本机令牌，和终端一样不问密码；访问密码只为局域网。
3. 关窗口：藏进托盘，网页视图留着，页面照旧连着核心、照旧自己弹通知；点托盘图标、通知，或者再开一次程序，窗口原样回来。
4. 托盘右键「退出」：外壳连核心一起关掉，彻底退出。
5. 安装包带核心、网页软件和外壳；不带终端界面。Linux 不自带 bubblewrap，deb、rpm、AUR 写依赖（2026-10-20 定的「有就用、不自带」）；不做 AppImage。
6. 第一版不签名、不做自动更新（谁装的谁升级）。
7. 单独的仓库 `miyu-agent/miyu-desktop`。先用 Tauri；WebKit 在 Linux、macOS 上的表现过不了再换 Electron（OpenCode 的桌面端走过这条路）。
